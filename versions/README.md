# Saved versions

Each folder is a frozen, offline copy of the app at that version (single HTML file).
Online: `https://mirabidhussain.github.io/structural-analysis-and-design-app/versions/<version>/`
APK of each version: GitHub Releases → tag `v<version>` (built by the "Build Android APK" workflow; a version's release is updated only while that version is current, then stays as it is).
