Analysis model — DXF (3D)

Columns, beams, braces, slabs, walls and supports on the layers IS StructDesign reads: COL_b×D, BEAM_b×D, BRACE_section, SLAB_t, WALL_t, SUPPORT_FIXED / SUPPORT_PIN. Units metres. In IS StructDesign: Frame & FE analysis → Model source → Import DXF drawing; sections and slab thicknesses come from the layer names.

Framing plans — DXF (2D)

One plan per floor with grids and bubbles, dimensions, columns, beams (double lines with marks and sizes), slabs, walls and a column schedule, side by side — opens in AutoCAD, LibreCAD, DraftSight or any DXF viewer.
